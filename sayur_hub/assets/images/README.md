# Panduan Standar Aset Gambar SayurHub
1. Format gambar disarankan menggunakan PNG atau WEBP dengan latar belakang transparan / putih bersih.
2. Rasio gambar produk adalah 1:1 (Square), resolusi minimal 512x512 piksel.
3. Penamaan berkas menggunakan format snake_case huruf kecil, contoh: `bayam_hijau.png`, `alpukat_mentega.png`.
